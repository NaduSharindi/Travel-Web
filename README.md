# Travel Web – Self-Study Project 🌍

This is a responsive travel website developed as part of my self-study practice to improve frontend web development skills. The site includes multiple sections such as homepage, destination packages, booking form, and contact page.

📍 **Live Demo:** [Visit Site](https://nadusharindi.github.io/Travel-Web/)

## 💡 Features
- Fully responsive layout
- Interactive navigation menu
- Travel packages and booking form
- Custom animations and transitions
- Clean UI using HTML, CSS, and vanilla JavaScript

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (vanilla)

## 🧠 Purpose
This project was created as a personal learning initiative to:
- Practice responsive design techniques
- Learn DOM manipulation with JS
- Build aesthetically pleasing layouts
